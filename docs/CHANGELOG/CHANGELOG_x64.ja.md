# x64 更新履歴

[簡体字中国語](CHANGELOG_x64.zh-CN.md) | [English](CHANGELOG_x64.en.md) | 日本語

本ファイルは独立した x64 ブランチの機能と変更を記録します。x86 作品の更新履歴とは分けて
管理します。

## 2026-11-11

### 追加

- **公式 thprac と GameFPS、Replay 速度、倍率表示を同期**（`e77dfcd`）

  thprac は th06nc の Update 呼び出しと Replay の加減速を引き継ぎます。`thprac64.dll` を検出
  すると、GameFPS は thprac のフレーム制限設定に追従し、Replay 早送りと標準 `xN` 表示は
  thprac に任せます。以前の `x8` 固定表示は解消しました。パッチは引き続きゲーム内で変更した
  低速移動アクションを読み取り、thprac の白い `/N` 低速表示を呼び出します。また、Update
  Chain 入口で実際に実行された論理フレームを数え、低速解除後に BGM を再配置します。

  公式 thprac で、非既定の早送り倍率表示、変更キーによる低速再生、BGM 再配置、両方の
  overlay の共存、60 FPS の維持を確認済みです。thprac がない場合は、従来の
  `ReplaySlowRate`、`ReplayFastRate`、`GameFPS` 経路をそのまま使用します。

## 2026-11-10

### 修正

- **ウィンドウがフォーカスを失っても overlay が消えなくなりました**（`284d165`）

  ゲームはウィンドウがバックグラウンドにあっても描画と Present を続けますが、overlay は
  以前、フォアグラウンドウィンドウの確認に失敗すると非表示になっていました。現在は
  Present FPS とフレーム処理時間の表示も含めて更新と描画を続けます。
  `ShowOverlay = 0` では従来どおり overlay を非表示にします。

## 2026-11-09

### 追加

- **独立した x64 DLL、ローダー、設定システムを追加**（`3f2f217`）

  `openinputlagpatch_x64.dll`、`oilp_loader_x64.exe`、SHA-256 によるバージョン判定、および
  グローバル設定 `%APPDATA%\ShanghaiAlice\oilp_custom\openinputlagpatch_x64.ini` を追加しました。
  ローダーはゲーム起動後のインジェクションと、実行中の対応プロセスへのアタッチの両方に対応します。

- **x64 ランタイムで GameFPS、Replay 低速再生、overlay、コンソール、Flip モデル機能を維持**（`3f2f217`）

  `GameFPS` はゲームのメインループのフレーム制限を引き継ぎます。Replay 中に左 Shift を押すと
  `ReplaySlowRate` の倍率で低速再生し、ゲーム標準の Replay 表示に倍率を出します。キーを離すと
  BGM を再同期します。`ShowOverlay` は別ウィンドウを作らずゲームの BackBuffer に実際の
  Present FPS とフレーム処理時間を描画するため、flip 表示を低下させません。
  `DebugConsole` はデバッグコンソールを開き、`ForceFlipDiscard` はスワップチェーン作成前に
  `DXGI_SWAP_EFFECT_FLIP_DISCARD` を要求します。

- **ゲーム内 U キーによる診断出力を維持**（`3f2f217`）

  `oilp_diag.txt` には x64 バージョン、設定、フック状態、スワップチェーンモデル、Replay
  低速再生、BGM 再同期、自機位置、直近 300 ゲームフレームの情報を記録します。

- **Replay 低速再生をゲーム自身の低速移動アクションで判定するよう変更**（`2a41c58`）

  物理的な左 Shift のポーリングをやめ、ゲームがリプレイ入力を論理状態へ書き込む前に、その
  フレームのリアルタイム入力合成結果を保存します。低速移動のアクションビットで減速するため、
  ゲーム内のキー変更、複数割り当て、外部ツールによる変更にも対応します。

- **Replay 早送り倍率 `ReplayFastRate` を追加**（`2a41c58`）

  既定値は原作と同じ `8` で、`1` から `128` まで指定できます。ゲームで設定された射撃キーを
  押している間、ゲーム標準の Replay 加速ループがこの倍率で実行され、左下の Replay 表示も
  対応する `xN` になります。

### 変更

- **overlay の旧補間フレームレート行を当面維持**（`3f2f217`）

  現在の x64 ビルドには補間がないため、この行は補間目標値ではなく実際の Present FPS を
  表示します。

### 修正

- **`ReplayFastRate` が 8 以外のときの起動時クラッシュを修正**（`2a41c58`）

  以前の WER 記録から、同じクラッシュが倍率機能の追加前にも発生していたことを確認しました。
  原因は overlay が D3D11 COM オブジェクトを解放する経路です。現在は排他ロックでリソースの
  ライフサイクルを直列化し、解放前にポインタを消去します。また
  `DllMain(PROCESS_DETACH)` のローダーロック内では D3D オブジェクトを解放しません。
  8 以外の倍率で繰り返し起動し、正常に開始できることを確認済みです。

### 削除

- **th06nc x64 の補間および Render Replay 実装を削除**（`3f2f217`）

  オブジェクト外挿、追加フレーム、追加 Present、描画チェーン再生、キャプチャーターゲットの
  履歴保護、D3D11 リソース追跡、x64 補間設定を削除しました。x64 の ini は
  `[Interpolation]` を読み込みません。共有 limiter に残る補間入口は既存の x86 ビルド専用で、
  x86 の補間機能には影響しません。

# 更新履歴

[簡体字中国語](Non-AI-CHANGELOG.zh-CN.md) | [English](Non-AI-CHANGELOG.en.md) | 日本語

## v1.14
- 東方文花帖DSのフレーム補間に対応（スペルカードEX-4の超高速弾は、弾が視覚的に途切れないよう補間しない）
- 自機補間アルゴリズムを改善し、自機補間が視覚的に半フレーム遅れる問題を解消（一部の画面でポーズすると、方向キーに反応して自機が揺れて見える場合がありますが、実際の動作には影響しません）
- th19とth20でゲーム起動時に `custom.exe` の `input method` を `Fast` に強制する機能を追加（この機能は上流リポジトリのバージョンですでに他の作品に追加されていました）
- [RUEEE版thprac](https://github.com/RUEEE/thprac)向けのレンダラーAPIを追加し、小数点作品のフレーム補間時にthpracのGUIが誤ってちらつく問題を修正（`thprac-CA` 以降のバージョンと互換）
- th06～th09.5で `AskWindowMode` を有効にした際の全画面選択ダイアログ、およびth10本来のウィンドウ全画面オプションをXで閉じられるように
- `oilp_loader.exe` のゲームexe選択ウィンドウで、中国語や日本語を含む実行ファイル名が正しく表示されるようにし、ゲーム選択の案内をシステムの言語設定に応じた多言語に対応
- ゲームが異常終了した際、不具合の調査に役立てるためOilPパッチがゲームのルートディレクトリへ自動的に `oilp_crash.txt` を生成するように
- `ReplaySpeedControl` を有効にした際、東方風神録と東方錦上京がゲーム本来のReplay早送り処理を引き続き使用する問題を修正
- `ReplaySpeedControl` を有効にした際、東方星蓮船のReplay早送り・低速再生が正常に動作しない問題を修正
- `ReplaySpeedControl` を有効にした際、東方錦上京のReplay早送り・低速再生速度をRUEEE版thpracから変更できるようにし、`GameFPS` もthpracによるゲームロジックのフレームレート変更と互換に（`thprac-CA` 以降のバージョンと互換）
- `ReplaySkipFPS` の値が比較的高い場合に、早送りキーを離してもReplayが加速したまま再生されることがある問題を修正
- `ReplaySkipFPS` または `ReplaySlowFPS` が0以下の場合にReplayの早送り・低速再生が超高速になる不具合を修正。0以下の場合は既定値の480fpsと30fpsを使用するように
- `ReplaySkipFPS` の既定値を480に変更
- th10～th15でステージ移行時などにゲームがクラッシュする可能性が高くなる問題を修正（現時点では実際の効果は未確認）
- dgVoodoo2の排他的全画面設定で画面を切り替えてゲームへ戻ると、4:3の画面が全画面に引き伸ばされる問題を修正（dgVoodoo2を検出すると `D3D9Ex` オプションを強制的に無効化。dgVoodoo2自体が低遅延の `flip model` を提供するため、遅延への悪影響はありません）
- 東方紅魔郷、東方妖々夢、東方永夜抄でフレーム補間を有効にした際、画面の上方付近で自機の弾が正しく描画されない問題を修正
- 東方紅魔郷と東方妖々夢でフレーム補間を有効にし、`PlayerBody = 0` にすると自機が画面左上に固定される問題を修正
- 東方妖々夢の左下の桜点およびスペルカード中のBonusが比較的高い値になった際に正しく表示されない問題を修正。ini設定の `FixTH07Cherry&BonusDisplay` で有効・無効を選択可能で、既定では有効
- 東方星蓮船のスコアが一定値を超えると逆算して表示される問題を修正。ini設定の `FixTH12ScoreDisplay` で有効・無効を選択可能で、既定では有効
- 一部作品（th10、th13～th17）で練習モードのReplayを再生し、最終ボス撃破後の会話が終了するとゲームがクラッシュする問題を修正。ini設定の `FixPracModeReplayCrash` で有効・無効を選択可能で、既定では有効
- 排他的全画面で4:3出力を強制するオプションを追加（この変更方法では画質が大幅に低下します。ゲームが4:3で表示されない場合は、まずグラフィックカードとディスプレイの設定を確認してください）。ini設定の `ForceRatio_4_3` で有効・無効を選択可能で、既定では無効
- 古いdgVoodoo2のDirect3DCreate8エントリにNVIDIAがインストールした破損したDetoursトランポリンを回避する設定を追加し、一部の比較的珍しい旧型PCでdx8ゲームが起動できない問題を修正（Windows 7 + Optimus + dgVoodoo2環境で発生）。ini設定の `BypassNvidiaD3D8Detour` で有効・無効を選択可能で、既定では無効
- Payday一味はホープ・ダイヤモンドを手に入れた
## v1.13
- 補間有効時に東方鬼形獣で次のステージへ進むとゲームがクラッシュする不具合を修正（影響を受けるバージョンは v1.11～v1.12。これらのバージョンを使用している方は必ず更新してください）
## v1.12
- 弾幕アマノジャクとバレットフィリア達の闇市場のフレーム補間に対応
- 東方妖々夢の一部レーザーで補間時に跳ねる問題を修正
- 東方風神録の魔理沙Cで、特定条件下におけるオプションの補間ズレを修正
- ゲーム検出処理を改善し、非オリジナル版でも起動不能にならず、警告を表示したうえで引き続き適用されるように
- 各種エラーダイアログと全画面で起動するかを選択するダイアログが中国語に対応
- Uキーの診断出力に、一部のPCで補間が機能しない状況を調査するためのパラメータを追加
- FullscreenRefreshRate の既定値を 0 に変更（排他的全画面時にゲームのリフレッシュレートがディスプレイの最大リフレッシュレートに従う）
- 真菌加速refillクリスタルを削除
## v1.11
- th09.5 東方文花帖のフレーム補間に対応
- 一部作品の内蔵スクリーンショットに余分なフレームが写る問題を、おそらくたぶん修正
- 補間機能を個別にオン/オフ可能に（敵弾とレーザー、自機本体、自機の弾の3部分に分かれ、既定ではすべて有効）
- グローバル設定ファイルに対応。ゲームフォルダに設定ファイルがない場合は、"%APPDATA%\ShanghaiAlice\oilp_custom\openinputlagpatch.ini" のグローバル設定を使用
- 補間有効時に東方妖々夢のリザルト画面が黒くなる問題、th10～th20 の各ステージ移行時のフェードイン/アウト速度が異常になる問題を修正
- 補間有効時に東方永夜抄の星光台風で唐突に横方向のレーザーが点滅する問題を修正
- 補間有効時に東方永夜抄の鈴仙戦で弾がぼやける際に背景が点滅する問題を修正
- 補間有効時に追加フレームで画面揺れが正しく復元されず、揺れが著しく弱くなる不具合を修正
- オーバーレイが表示されるべきでない一部の場面でも小さな黒い矩形が表示される問題を修正
- th18～th20 の Steam 版に対応
- th19 のサードパーティ製ネット対戦ツール Ju.N.Owen が有効な場合は、問題を防ぐため補間を自動的に強制オフ
- スティーブンを削除
## v1.10
- th06～th08 に対応
- vpatch による DX8 世代の旧作向け特殊最適化を多数移植（一部は ini 設定で変更可能ですが、既定設定の維持を推奨）
- ini 設定変更：補間の既定値を 1 に変更。パラメータが 1 の場合、目標補間フレーム数がディスプレイのリフレッシュレートに自動的に同期
- ini 設定変更：ShowOverlay = X のパラメータは次の通り。X=0：どちらも表示しない X=1：補間フレームレートのみ表示 X=2：レイテンシのみ表示 X=3：両方表示。既定は X=1（レイテンシ表示は thprac でも確認でき、2つのオーバーレイが画面下部の敵識別表示を隠すおそれがあるため）
- Herobrine を削除
- 注：DX8 作品では開発中に多数の不具合を確認し、可能な限り修正してきましたが、現時点で安定しているとは保証できません。予期しない問題が発生する可能性があるため、注意してください。
